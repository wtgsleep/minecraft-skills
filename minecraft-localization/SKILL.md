# 模组汉化与文案
从指定文件或项目定位源语言、目标语言、术语和实际文件格式；默认只改语言内容，不变更注册 ID、玩法、模型或资源路径。

- 沿用已有术语与用户指定名称。只为有歧义且影响含义的词提供候选，不逐项询问。文案不夸大尚未实现的能力。
- 保护键名、%s/%d/%1$s 等格式占位符、转义序列、换行和游戏格式代码；比较占位符类型与数量，允许目标格式支持的有意重排。
- 不翻译资源标识符、命令、URL 或代码；目标语言缺条目时补译，不静默删除已有独有条目。
- 按目标版本处理 JSON、旧版 .lang 或 Bedrock 格式，不套用同一种解析器。JSON 检查语法、重复键与 UTF-8，避免普通解析器默默覆盖重复键。
- 大批量按文件或命名空间分组，仅查看相关上下文，不每批重复载入全仓。保持文件既有布局，尽量减少无关 diff。
- UI 长度无法实测时注明可能截断；不把静态语言校验宣称为游戏内显示正常。只在修改需要时做相关资源/构建检查。

交付翻译文件、关键术语选择及未解决歧义。仅做文案方案时不写入项目；翻译第三方内容需尊重用户提供范围与授权，不上传到外部服务。
