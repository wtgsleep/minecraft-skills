# 视频剪辑方案
先利用已有信息确定用途、目标时长、横竖屏、受众和素材；不为未提供素材虚构画面、对白或精准时间码。

- 有视频访问能力时先检查时长、画面、音轨和帧率，再围绕关键片段抽样查看；不要默认逐帧解析整个长视频。
- 无法观看或听取素材时明确限制，依据用户描述给结构草案；待定位片段标为“待确认”，不能捏造已看到的精彩瞬间或转录。
- 时间轴区分源文件的入点/出点与成片时间；每段写用途、画面、旁白/字幕、转场。用可核对的时长求和，考虑转场重叠。
- 转录和创作旁白分别标明。只有可靠时间信息才输出正式 SRT/VTT，并检查时间递增、结束晚于开始及整体范围；否则提供未定时字幕稿。
- 不默认添加未经授权的音乐、商标或人脸素材；不把字幕掩盖重要画面。根据语言和节奏检查字幕可读性。

默认交付方案，不自动调用付费生成服务、上传素材或发布视频。用户明确要求成片时，先确认本机编辑工具/FFmpeg与素材可用，保留原片，输出新文件；检查导出时长、音轨、字幕和关键画面。没有执行渲染就不能称为成片。缺工具时提供可执行方案或请求需要的条件，不承诺技能本身附带剪辑能力。
