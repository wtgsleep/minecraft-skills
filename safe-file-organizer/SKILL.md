# 文件批量整理
只处理用户明确指定目录。先检查范围、数量、文件类型与分类规则，不读取不必要的文件内容；目录不明确时询问，不默认扫描用户主目录或磁盘。

## 计划与执行
- 先生成源路径→目标路径清单；检查路径规范化、大小写冲突、非法名称、同名覆盖、路径长度和嵌套目标。符号链接与 junction 默认不跟随，不让解析后路径越出范围。
- 用户只要方案或查重时保持只读。批量移动/重命名前展示数量、示例和冲突策略，获得对该计划的确认；已明确批准同一计划不重复询问。
- 默认不覆盖、不删除。遇到冲突跳过并报告，或采用用户批准的后缀规则。查重先按大小再按内容哈希，同名/同尺寸不等于重复；重复文件也不自动删除。
- 源文件在计划后变化时跳过并更新计划。Windows 使用单一 shell 的原生文件命令和 LiteralPath，避免字符串拼接执行路径；不跨 shell 组合删除操作。
- 在执行前保存计划，逐项记录成功、失败及实际目标。先小批验证；失败时停止受影响操作，不悄悄改规则。跨卷移动先确认副本完整再按授权处理源文件。
- 验证文件数量和必要哈希，提供记录及撤销映射；撤销前检查目标是否又被修改，不承诺任何时候都能自动恢复。

不要整理运行中的项目依赖、系统目录或云端同步目录而不说明风险。删除属于单独操作，需明确对象与授权；优先可恢复方式，不能用“整理”推定永久删除授权。
